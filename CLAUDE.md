# Convenciones del repositorio

## Commits y Pull Requests
- No añadir atribuciones automáticas, *co-authors* de herramientas, firmas de
  asistentes ni enlaces de sesión en los mensajes de commit ni en las
  descripciones de Pull Request.
- Los mensajes describen únicamente el cambio técnico.

## Ramas
- Las ramas nuevas usan el prefijo `code/` (por ejemplo, `code/mi-cambio`).
